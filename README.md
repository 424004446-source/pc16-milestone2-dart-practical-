 **Project Overview & Description**

Designed for PC16 Terminal Assessment 2, this deliverable integrates all core Dart concepts from Weeks 7 through 11 into a fully executable console application. The project highlights the practical application of abstract interfaces, single inheritance, composition via mixins (`WirelessCharging`), and method overriding to achieve object polymorphism within List and Map collections. Additionally, it addresses non-blocking concurrency by embedding asynchronous background operations directly into the class hierarchy, proving through real-time console logging that the main execution loop remains responsive during simulated multi-second server delays.
